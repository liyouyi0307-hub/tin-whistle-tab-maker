# tin-whistle-sheet-generator

Tin Whistle Sheet Generator - An online tool for generating sheet music for the tin whistle

## Introduction

tin-whistle-sheet-generator is a web-based tool for generating tin whistle sheet music. It converts numeric notation or simplified musical notation into tin whistle finger diagrams, making it easy for learners to quickly view and play tunes.

## Features

- **Sheet Generation**: Input numeric or simplified notation to automatically generate corresponding tin whistle finger diagrams
- **Visual Display**: Clear and intuitive finger diagram illustrations
- **Print Support**: Supports printing sheet music (with print-optimized styling)
- **Error Detection**: Real-time display of input errors
- **Sample Data**: Built-in sample tunes (e.g., KingdomDance.json)

## How to Use

1. Enter numeric or simplified notation in the input area
2. Click the Generate button
3. View the generated tin whistle finger diagram
4. Click the Print button to print the sheet music
