

# tin-whistle-sheet-generator

竖笛谱生成器 - 一个用于生成竖笛（tin whistle）曲谱的在线工具

## 简介

tin-whistle-sheet-generator 是一个基于 Web 的竖笛曲谱生成工具。它可以将简谱或数字谱转换为竖笛指法图，方便竖笛学习者快速查看和演奏曲目。

## 功能特性

- **曲谱生成**：输入简谱或数字谱，自动生成对应的竖笛指法图
- **可视化展示**：清晰直观的指法图示
- **打印支持**：支持打印曲谱（包含打印优化样式）
- **错误提示**：实时显示输入错误信息
- **示例数据**：内置示例曲目（如《KingdomDance.json》）

## 使用方法

1. 在输入区域输入简谱或数字谱
2. 点击生成按钮
3. 查看生成的竖笛指法图
4. 可点击打印按钮打印曲谱
